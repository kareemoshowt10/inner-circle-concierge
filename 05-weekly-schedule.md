# 05 — Weekly Schedule

The whole model must fit inside 2 days/week (adding a 3rd only when recurring revenue justifies it). Structure beats hustle.

## The two days

### Day A — Delivery Day
| Block | Work |
|---|---|
| 9:00–12:00 | Install work (knowledge bases, AI setup, automations) — deep work, no calls |
| 12:30–2:00 | Client training / handoff sessions |
| 2:00–4:00 | Concierge Care queue: monitoring, tweaks, support hours |
| 4:00–4:30 | Log hours against package scopes; queue change orders |

### Day B — Growth Day
| Block | Work |
|---|---|
| 9:00–10:00 | Inner Circle group coaching call (weekly; recorded for the member library) |
| 10:00–12:00 | Sales calls / discovery calls (2–3 max) |
| 12:30–2:30 | Content: one case study, tip post, or email to the list |
| 2:30–4:00 | 1:1 coaching sessions and VIP strategy calls |
| 4:00–4:30 | Pipeline + funnel tracking sheet update |

## Rules that protect the schedule

1. **Everything is booked, nothing is "whenever."** Scheduling link only offers Day A/B slots.
2. **Batch installs.** One property's knowledge base start-to-finish in one sitting beats spreading it across weeks.
3. **48-hour response SLA** for retainer clients — stated in writing, so 5 days off doesn't feel like neglect.
4. **The AI does the drafting.** Client FAQs, SOPs, and message sequences are drafted with the same AI stack being sold — eat the dog food, halve the delivery hours.

## Capacity limits (what keeps promises keepable)

| Offering | Max concurrent | Why |
|---|---|---|
| Setup projects in flight | 2 | One Day A can advance two installs |
| Concierge Care clients | 12 | ~2 hrs each/mo ≈ 24 hrs ≈ 6 half-days |
| VIP clients | 6 | 1:1 sessions fit in Day B afternoons |
| Membership | Uncapped | Group call + community scale without added hours |

## When to add Day C

Add a third day when **recurring revenue exceeds ~$3K/mo** or Care hits its 12-client cap with a waitlist. Day C mirrors Day A (pure delivery), which roughly doubles install throughput and raises the Care cap to ~20. That's the bridge from the Conservative to the Target scenario in [02](02-packages-and-pricing.md).
